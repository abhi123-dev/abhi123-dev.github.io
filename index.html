It is a desktop application that runs entirely on your computer. Your connection details stay with you. Your queries stay with you. Your data never takes a detour through someone else’s server.

plugboard is built for speed and simplicity. It opens quickly, responds instantly, and keeps the interface out of your way. Whether you are checking a single row, exploring a new database, or running everyday queries, plugboard gives you a clean workspace without the clutter, the sign-up screens, or the nagging upgrade prompts.

It is a practical alternative to heavier database clients and a comfortable home for anyone who believes that local software should feel local. Install it, open it, connect to your database, and get to work.

🔌 Works With the Databases You Already Use

plugboard supports a wide range of popular databases, so you do not need a different tool for every project. The application is designed to handle both relational databases and modern data stores in one place.

  • PostgreSQL — for reliable, feature-rich relational data.

Your database connection details are sensitive. There is no account system, no cloud sync, and no telemetry. The application does not send your activity to a remote service.

This local-first approach is not an afterthought. It is the core idea behind plugboard. You should not have to trade your privacy for a convenient database client. With plugboard, you get a fast desktop tool and full control over your own workspace.

🧭 Your First Five Minutes

Once plugboard is open, the first step is to create a connection. Select the type of database you want to work with, then enter the details your database administrator or hosting provider gave you. These typically include a host name, a port, a database name, a username, and a password. For a local SQLite file, you simply choose the file on your computer.

After you connect, you can browse your tables, inspect columns, and open a query window. Take a moment to explore the interface at your own pace. There is no timer and no setup wizard rushing you along. plugboard is meant to be ready when you are.

If you work with more than one database, you can keep separate connections and switch between them as needed. This makes plugboard useful for personal projects, team applications, and learning environments alike.

💡 Everyday Tips

  • Keep your connection details in a password manager so you can set up plugboard quickly on a new computer.
  • Use descriptive connection names. If you work with development and production databases, clear names help you avoid confusion.
  • Start with a read-only account when you are exploring an unfamiliar database. It is a simple habit that protects your data.
  • Close connections you are not using. This keeps your workspace tidy and makes it easier to find the database you need.

These small habits make database work more comfortable, especially if you are new to tools like this. plugboard is designed to support careful, focused work rather than overwhelm you with options.

❓ Troubleshooting the Basics

If the download does not start, check your browser’s download settings and make sure pop-ups or automatic downloads are not being blocked. If you cannot find the file, open your Downloads folder and sort by date. If the application does not open, try downloading it again from the official page to make sure the file was saved completely.

If you can open plugboard but cannot connect to a database, double-check the host, port, username, and password. A small typing mistake is the most common cause of connection problems. Also confirm that your database allows connections from your computer and that any firewall rules are set correctly.

For issues that are not covered here, visit the project page and look through the available information. Because plugboard is open source, the project page is also the best place to report a problem or ask a question.

🧩 System Requirements

plugboard is a desktop application for Windows. A reasonably modern computer is all you need.
